# Product Backlog

## Project Name
Card Game Application

## Project Description
Our project is a JavaFX card game. We will use a normal 52-card deck. The program can show the cards, shuffle the cards, and later we can add a simple game. We want the program to be easy to use and easy to understand.

## Must-Have Features

| ID | Feature | Description | Estimate |
|----|---------|-------------|----------|
| 1 | Show 52 Cards | Show all 52 cards on the screen. | 5 |
| 2 | Shuffle Cards | Add a button to shuffle the cards. | 3 |
| 3 | Card Images | Use the correct image for each card. | 5 |
| 4 | Create Deck | Make a deck with 52 cards. | 3 |
| 5 | Player Card | Show a card for the player. | 3 |
| 6 | Computer Card | Show a card for the computer. | 3 |
| 7 | Compare Cards | Compare the player card and computer card. | 5 |
| 8 | Score | Keep the score for the player and computer. | 5 |

## Nice-to-Have Features

| ID | Feature | Description | Estimate |
|----|---------|-------------|----------|
| 9 | Restart Button | Restart the game and reset the score. | 2 |
| 10 | Win Message | Show who wins the game. | 3 |
| 11 | Instructions | Show simple game instructions. | 3 |
| 12 | Background | Add a nice card table background. | 2 |
| 13 | Sound | Add simple sound effects. | 5 |

## Development Order

1. Create the 52-card deck.
2. Show all cards.
3. Add the card images.
4. Add the Shuffle button.
5. Add player and computer cards.
6. Compare the cards.
7. Add the score.
8. Test the program.
9. Add extra features if we have time.

## Notes

This is our first product backlog. We may change or add features later when we work more on the final project.
