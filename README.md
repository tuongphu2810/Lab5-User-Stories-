# Lab 5 - User Stories

## Project Description

This project is a JavaFX Card Display Application.

The program uses a standard 52-card deck. It displays all 52 cards on the screen and has a Shuffle button. When the user clicks the Shuffle button, the cards are shown in a random order.

## Features

- Displays all 52 playing cards
- Uses card images
- Shows the cards in a JavaFX window
- Has a Shuffle button
- Randomizes the card order when the button is clicked

## Project Files

- `Card.java` - stores information about each card
- `Deck.java` - creates the 52-card deck and shuffles the cards
- `CardDisplayApp.java` - displays the cards and the Shuffle button
- `PRODUCT_BACKLOG.md` - contains the product backlog for the project

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure JavaFX is installed.
3. Run `CardDisplayApp.java`.
4. The 52 cards will appear on the screen.
5. Click the Shuffle button to shuffle the cards.

In the High Card game:
- The player and computer each get one card.
- The higher card wins the round.
- The winner gets one point.
- A tie gives no points.
